# Geovex OS desktop app

The installers for the Geovex OS desktop app (Mac and Windows), and the feed the app updates itself from.

The app is a locked-down window around https://app.geovex.co.uk. It holds no data and no secrets: you still sign in as yourself.
Its source and release workflow live in Geovex's private app repository. This repository holds only the built installers.

- Mac: `Geovex-OS-mac.dmg` from the newest release.
- Windows: `Geovex-OS-Setup.exe` from the newest release.
